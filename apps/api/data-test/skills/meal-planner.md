# meal-planner

Sestaví jídelníček na týden.

## Kdy použít
V neděli večer, než plánuješ nákup na týden.

## Postup
1. Načti vstup a ověř, že dává smysl.
2. Proveď hlavní práci skillu (sestaví jídelníček na týden).
3. Vrať shrnutí výsledku a zapiš výstup na disk.
