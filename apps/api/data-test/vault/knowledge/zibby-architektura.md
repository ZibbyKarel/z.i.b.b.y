# ZIBBY architektura

Soubory jsou jediný zdroj pravdy. Démon běží jako služba na hostu, agenty pouští jako child procesy.

- Skilly: `~/zibby/skills/<id>/SKILL.md`
- Agenti: `~/zibby/agents/<id>.agent.md`
- Approval gate je hard-enforcement vrstva.

Viz [[claude-sdk]], [[git-workflow]].
