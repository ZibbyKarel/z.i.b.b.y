Forge owns the delivery loop: Architekt → Kodér ⇄ Code-Review → Tester →
Dokumentátor. It manages worktrees, checkpoints, and PR outputs — the kovárna
doručení (delivery forge) that turns an operator goal into working, reviewed
code. Mostly built.
