- implmentovat učící se mechanismus z CR u PR. Use Case: pokud uděláme PR a někdo tam napíše commenty, tak je opravíme ale musíme někde uchovávat kolikrát se co commentovalo. Pokud se to bude vícekrát opakovat tak bychom to v následujících otevřených PR neměli opakovat.
- detekce cyklů v roadmap závislostech (`dependsOn`). Deterministický DFS nad grafem roadmap itemů projektu — spustit při importu/re-syncu a při ručním přidání hrany. Item v cyklu se nesmí nikdy automaticky dispatchnout (zůstane blokovaný) a musí být v UI viditelně označený, aby operátor cyklus rozsekl. Záměrně odloženo z první verze Roadmapy.
- `countRunning`/`countRunningGlobal` (`apps/api/src/budget/budget.service.ts`) nepočítají goal runy, přestože scheduler bere ukončený goal run jako uvolnění slotu (`TERMINAL_GOAL` → `drainQueues()`). Oba čítače tedy podhodnocují, dokud běží goal runy. Vědomě odloženo ve fázi 125c (DECISIONS.md D-007): opravit se musí **oba najednou**, jinak by se stejná zátěž chovala jinak pod projektovým a systémovým stropem.
- `roadmapItemIdForSource` (`libs/contracts/src/roadmap/roadmap-item.schema.ts`) spojuje `<integrationId>-<externalId>` prostou konkatenací, takže dvě různé dvojice mohou teoreticky kolidovat na stejné id (a tím i na stejný soubor). Odpovídá doslovné specifikaci plánu fáze 125; zpřísnit lze délkově prefixovaným spojením — pozor, změna přepíše id všech už naimportovaných položek.
